# Shape Detector + Fruit Classifier Pipeline

This pipeline trains two separate models:

1. A YOLO11n shape detector trained from scratch with class ids `0..3`.
2. A cube-crop fruit classifier: `apple`, `orange`, `banana`, `pineapple`,
   and optionally `none`. Synthetic training crops are generated by estimating
   the visible cube face and perspective-warping fruit images onto that face.

## Shape Detector

Use the shape-only data config:

```powershell
python scripts/check_dataset.py `
  --data dataset/data_shapes.yaml `
  --profile shape4 `
  --require-non-empty `
  --strict

python src/train.py `
  --from-scratch `
  --model yolo11n.pt `
  --data dataset/data_shapes.yaml `
  --epochs 100 `
  --imgsz 640 `
  --name shape_yolo

python src/validate.py `
  --model runs/detect/shape_yolo/weights/best.pt `
  --data dataset/data_shapes.yaml `
  --split val
```

`--from-scratch` converts `yolo11n.pt` to the matching architecture config
`yolo11n.yaml`, so the detector does not start from pretrained weights.

## Fruits 360 Source Dataset

Prepare a filtered Fruits 360 dataset:

```powershell
python scripts/prepare_fruits360.py `
  --source-root C:\path\to\fruits-360 `
  --output-root dataset/fruits360 `
  --clear
```

The script reads the usual Fruits 360 `Training` and `Test` folders, keeps only
class folders whose names match apple, orange, banana, or pineapple, and writes:

```text
dataset/fruits360/
  train/apple/
  train/orange/
  train/banana/
  train/pineapple/
  val/...
  test/...
```

This dataset is still plain fruit imagery. It is used as sticker source
material, not as the final cube-crop classifier dataset.

## Synthetic Cube-Fruit Dataset

First annotate visible cube faces manually:

```powershell
python scripts/annotate_cube_faces.py `
  --data dataset/data_shapes.yaml `
  --output dataset/cube_face_annotations.json `
  --splits train val test `
  --display-scale 3
```

Generate cube-crop classifier data from the shape dataset, manual face
annotations, and Fruits 360:

```powershell
python scripts/synthesize_cube_fruit_dataset.py `
  --data dataset/data_shapes.yaml `
  --fruit-root dataset/fruits360 `
  --output-root dataset/cube_fruits_synthetic `
  --face-annotations dataset/cube_face_annotations.json `
  --output-split-mode random `
  --train-ratio 0.7 `
  --val-ratio 0.15 `
  --test-ratio 0.15 `
  --max-sticker-faces 2 `
  --shadow-prob 0.45 `
  --shadow-min-factor 0.35 `
  --shadow-max-factor 0.85 `
  --global-brightness-min 0.70 `
  --global-brightness-max 1.00 `
  --clear
```

The script reads cube boxes from class id `0`, crops each cube, uses the manual
face quadrilaterals from `dataset/cube_face_annotations.json`, and applies
`cv2.getPerspectiveTransform` plus `cv2.warpPerspective` to paste fruit images
onto the selected face. `--output-split-mode random` reshuffles all annotated
cube crops into the requested classifier split ratio instead of keeping the
original YOLO split.

If a cube has multiple annotated visible faces, each synthetic image uses one
fruit class and pastes it onto a non-empty random subset of those faces. The
fruit class is shared, but each selected face can use a different source image
from that class. Use `--sticker-face-mode all` to force every annotated face, or
`--sticker-face-mode one` to force exactly one face. By default,
`--max-sticker-faces 2` prevents stickers from being pasted onto more than two
faces in one synthetic image.

Lighting augmentation can add soft local shadows and uniform global darkening
after the sticker has been pasted. It keeps the original color balance, so fruit
classes are not shifted by red or yellow synthetic lighting.

The output is an ImageFolder-style classifier dataset:

```text
dataset/cube_fruits_synthetic/
  train/apple/
  train/orange/
  train/banana/
  train/pineapple/
  train/none/
  val/...
  test/...
  metadata.csv
```

`none` images are original cube crops without a fruit sticker. This is more
stable than relying only on a probability threshold for no-fruit decisions.

## Fruit Classifier Training

Train the classifier:

```powershell
python src/train_fruit_classifier.py `
  --data-root dataset/cube_fruits_synthetic `
  --epochs 30 `
  --imgsz 100 `
  --output runs/classify/cube_fruits
```

The class order is discovered from the training folders. With the synthetic
dataset, the final layer outputs five logits in this order:

```text
0 apple
1 orange
2 banana
3 pineapple
4 none
```

The best checkpoint is saved to:

```text
runs/classify/cube_fruits/best.pt
```

## Cube Crop Inference

Run the classifier on a full image or on a cube bbox crop:

```powershell
python src/infer_fruit_classifier.py `
  --model runs/classify/cube_fruits/best.pt `
  --image sample.jpg `
  --bbox 120 80 260 220 `
  --threshold 0.7
```

Output is JSON. `fruit_kind` is `null` when the classifier predicts `none` or
when no fruit probability reaches the threshold.
